# yejin-jamcoding

HTML/CSS 학습용 개인 저장소입니다. 주차별 과제 결과물을 폴더로 정리합니다.

## 배포 주소 (GitHub Pages)

https://xhae123.github.io/yejin-jamcoding/

주소 끝에 `?week=숫자`를 붙이면 해당 주차 과제로 이동합니다.

| 주차 | 링크 |
| --- | --- |
| week-1 | https://xhae123.github.io/yejin-jamcoding/?week=1 |
| week-3 | https://xhae123.github.io/yejin-jamcoding/?week=3 |

새 주차 과제를 추가할 때는 `week-N` 폴더를 만들고 그 안에 `index.html`을 넣기만 하면 `?week=N` 주소로 바로 접속됩니다.

## 폴더 구조

| 폴더 | 과제 내용 |
| --- | --- |
| [`week-1`](./week-1) | 쇼핑몰 상품 상세 페이지의 상단 화면(상품명, 가격/할인율, 배지, 리뷰, 수량 선택, 결제 금액)을 이미지대로 HTML/CSS만으로 구현하기. 아이콘(하트, 공유, 별점, 리뷰 사진 등)은 svg/이미지 대신 적절한 텍스트로 대체했습니다. |
| [`week-3`](./week-3) | 그래픽 디자인 포트폴리오(1인) 페이지. 바닐라 HTML/CSS/JS로 구현했으며 에디토리얼 레이아웃, 스크롤 마스크 리빌·패럴랙스, 반응형(모바일/데스크탑), 라이트·다크 테마를 포함합니다. 이미지는 더미 플레이스홀더(SVG)로 채워 두었고, 실제 콘텐츠는 `CLAUDE.md` 인터뷰 가이드를 따라 교체합니다. |

## 실행 방법

각 주차 폴더의 `index.html` 파일을 브라우저로 열면 결과를 확인할 수 있습니다.
